## Introduction
This project aims to estimate house prices using a linear regression model with variable transformations. By analyzing various property features—such as area and location—we’ll develop a model capable of predicting market prices under different scenarios and conditions. The project’s storytelling revolves around the challenge of making property valuations more accessible and accurate, assisting both buyers and sellers in the negotiation process.

## Dataset
We’ll use the dataset house_prices.csv, adapted from a well-known Kaggle dataset called House Prices. We’ve made some adjustments to the original dataset to ensure a better learning experience for the techniques covered in this project.

You can find the dataset in the data folder of this repository or follow the instructions in the project to read the data directly from this repository via a URL.
Below are the variables available in our dataset:
price: The sale price of the property in Brazilian Reais (BRL). This is the target variable we aim to predict based on property attributes.
first_floor_area: The area of the first floor, measured in square meters.
has_second_floor: A binary variable indicating whether the property has a second floor (1 for "yes," 0 for "no").
backyard_area: The area of the backyard, measured in square meters.
subway_distance: Distance to the nearest subway station, in kilometers.
park_distance: Distance to the nearest park or square, in kilometers.

## Challenge
The challenge of this project consists of:
Implementing a linear regression model that uses multiple variables to predict house prices.
Performing variable transformations to improve the model’s performance.
Evaluating the model’s accuracy using well-known Scikit-Learn metrics.
Interpreting the model’s coefficients to understand the impact of each variable on house prices.
